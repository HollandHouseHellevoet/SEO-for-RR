# On-Page SEO Audit Checklist

Evaluate the on-page optimization of each domain. On-page SEO directly controls what search engines display in results and how they understand your content.

**Apply to each domain:** RojasReport.com | POH | FAH | AHA | Academic

---

## Title Tags

- [ ] Every page has a unique title tag
- [ ] Title length: 50-60 characters (will not be truncated in SERPs)
- [ ] Primary keyword appears near the beginning of the title
- [ ] Brand name included (e.g., "| The Rojas Report" or "| Dutch Rojas")
- [ ] Titles are compelling and encourage clicks
- [ ] No duplicate titles across pages or subdomains

**Examples for RojasReport domains:**
```
Physician-Owned Hospitals: The Case for Independence | The Rojas Report
Certificate of Need Laws Are Killing Competition | Dutch Rojas
AHA Lobbying Spending Hits Record High in 2025 | The Rojas Report
```

## Meta Descriptions

- [ ] Every page has a unique meta description
- [ ] Length: 120-160 characters
- [ ] Includes primary keyword naturally
- [ ] Includes a call to action or value proposition
- [ ] Accurately describes page content
- [ ] No duplicate descriptions across pages

**Example:**
```
Dutch Rojas breaks down physician-owned hospital legislation state by state. 
Daily analysis on Certificate of Need, hospital consolidation, and physician independence.
```

## Heading Structure

- [ ] Exactly one H1 per page
- [ ] H1 contains the primary keyword for that page
- [ ] H1 differs from the title tag (but covers the same topic)
- [ ] Headings follow logical hierarchy: H1 > H2 > H3 (no skipping)
- [ ] Headings are descriptive (not generic like "Introduction" or "Details")
- [ ] Subheadings (H2/H3) break content into scannable sections
- [ ] Headings match questions users would ask (helps AI citation)

## Content Optimization

- [ ] Primary keyword appears in first 100 words
- [ ] Primary keyword used naturally throughout (not stuffed)
- [ ] Related keywords and semantic variations included
- [ ] Content is comprehensive and answers the user's search intent
- [ ] Above-the-fold content is immediately valuable (not just navigation)
- [ ] Short paragraphs (2-4 sentences) for readability
- [ ] Bullet points and numbered lists where appropriate
- [ ] Important information is not hidden in tabs, accordions, or behind JS

## Images

- [ ] All images have descriptive alt text
- [ ] Alt text includes relevant keywords where natural (not stuffed)
- [ ] Image file names are descriptive (e.g., `physician-owned-hospital-stats.jpg`, not `IMG_0042.jpg`)
- [ ] Images are appropriately sized (not oversized originals)
- [ ] Images use modern formats (WebP, AVIF) with fallbacks
- [ ] Lazy loading enabled for below-the-fold images
- [ ] Images have width/height attributes set (prevents CLS)

## Internal Linking

- [ ] Every page has internal links to related content
- [ ] Anchor text is descriptive and keyword-relevant
- [ ] Cross-subdomain linking is strategic:
  - RojasReport.com links to relevant POH, FAH, AHA, Academic articles
  - Subdomain articles link back to the main domain
  - Related articles across subdomains link to each other
- [ ] No broken internal links
- [ ] Important pages have the most internal links pointing to them
- [ ] Navigation menu links to key sections
- [ ] Footer links to important pages (About, Contact, key topics)

## Social Meta Tags

### Open Graph (Facebook, LinkedIn)
- [ ] `og:title` — page title
- [ ] `og:description` — page description
- [ ] `og:image` — share image (1200x630px recommended)
- [ ] `og:url` — canonical URL
- [ ] `og:type` — article, website, etc.
- [ ] `og:site_name` — "The Rojas Report"

### Twitter Cards
- [ ] `twitter:card` — summary_large_image
- [ ] `twitter:title` — page title
- [ ] `twitter:description` — page description
- [ ] `twitter:image` — share image
- [ ] `twitter:site` — @RojasReport (or correct handle)

## URL Optimization

- [ ] URLs include target keywords
- [ ] URLs are short and descriptive
- [ ] No stop words in URLs (a, the, is, etc.) unless needed for clarity
- [ ] Consistent URL structure across the site
