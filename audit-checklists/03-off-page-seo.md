# Off-Page SEO Audit Checklist

Evaluate external signals that influence domain authority and search rankings. Off-page SEO focuses on how the broader internet perceives and references your domains.

**Apply to each domain:** RojasReport.com | POH | FAH | AHA | Academic

---

## Backlink Profile

- [ ] **Backlink audit completed** using Ahrefs, Moz, or SEMrush
- [ ] Total number of referring domains documented
- [ ] Domain Rating / Domain Authority score noted
- [ ] **Quality assessment:**
  - Links from healthcare industry sites
  - Links from news/media outlets
  - Links from government (.gov) or academic (.edu) sources
  - Links from industry organizations
- [ ] **Toxic links identified** and disavowed if needed
  - Spammy or irrelevant domains linking to you
  - Paid link schemes
  - Link farms
- [ ] **Competitor comparison** — how does your backlink profile compare to competitors in healthcare media?

## Link Building Opportunities

- [ ] **Industry directories:**
  - Healthcare media directories
  - Physician advocacy organizations
  - Veteran-owned business directories
  - Media/journalism directories
- [ ] **Guest posting targets:**
  - Healthcare publications (Becker's, Modern Healthcare, STAT News)
  - Policy/advocacy outlets
  - Business publications (Forbes, Bloomberg contributor programs)
- [ ] **HARO / Connectively** — sign up as a healthcare industry source
- [ ] **Podcast appearances** — link back to RojasReport from show notes
- [ ] **Conference/speaking engagements** — event pages link to speaker profiles
- [ ] **Press releases** — major announcements distributed with backlinks

## Cross-Domain Linking Strategy

- [ ] **Hub-and-spoke model implemented:**
  - RojasReport.com (hub) links to all subdomains
  - Each subdomain links back to RojasReport.com
  - Related content across subdomains cross-linked
- [ ] **Consistent navigation** across all subdomains referencing the network
- [ ] **Shared footer** or "Part of The Rojas Report Network" on all subdomains

## Brand Mentions & Citations

- [ ] **Track unlinked mentions** of:
  - "Dutch Rojas"
  - "The Rojas Report"
  - "MedMerge"
  - "PhyCap Fund"
  - "ROJAS MEDIA"
- [ ] **Request links** for unlinked brand mentions
- [ ] **Google Alerts** or BrandMentions set up for key terms
- [ ] **Social media mentions** tracked and engaged

## Social Media Presence

- [ ] All social profiles created and active:
  - LinkedIn (Dutch Rojas personal + company pages)
  - Twitter/X (@RojasReport or appropriate handle)
  - YouTube (if video content exists)
  - Substack / newsletter platform
- [ ] Social profiles link back to RojasReport.com
- [ ] Consistent branding across all platforms
- [ ] Regular posting schedule
- [ ] Content shared from all subdomains, not just main domain
- [ ] Social profiles referenced in Person/Organization schema (sameAs)

## NAP Consistency

- [ ] **Name, Address, Phone** identical across all listings
- [ ] Business name consistent: "The Rojas Report" / "MedMerge" / etc.
- [ ] Any directory listings updated with current information

## Local SEO (if applicable)

- [ ] Google Business Profile claimed and optimized
- [ ] Bing Places listing
- [ ] Industry-specific listings
