# Master SEO + AI/LLM Audit Checklist

This is the complete audit checklist for all RojasReport domains. Each item should be checked for every domain in scope. For detailed guidance on each category, see the linked sub-checklists.

**Domains:** RojasReport.com | POH.rojasreport.com | FAH.rojasreport.com | AHA.rojasreport.com | Academic.rojasreport.com

---

## A. Technical SEO
> [Detailed checklist](01-technical-seo.md)

- [ ] HTTPS enabled with valid SSL certificate
- [ ] robots.txt exists and is correctly configured (including AI crawler rules)
- [ ] XML sitemap exists, is valid, and submitted to Google Search Console
- [ ] Clean URL structure (hyphens, no unnecessary parameters, logical hierarchy)
- [ ] Site architecture: important pages reachable within 3 clicks of homepage
- [ ] Core Web Vitals pass: LCP < 2.5s, CLS < 0.1, INP < 200ms
- [ ] Mobile-responsive design (passes Google Mobile-Friendly Test)
- [ ] No broken links (4xx/5xx errors)
- [ ] Canonical tags present and correct on all pages
- [ ] 301 redirects in place for any moved/renamed pages
- [ ] No duplicate content issues (across pages or across subdomains)
- [ ] Page speed optimized (compressed images, minified CSS/JS, lazy loading)
- [ ] Structured data validates in Google Rich Results Test
- [ ] Server returns proper HTTP status codes
- [ ] GZIP/Brotli compression enabled
- [ ] Browser caching configured

## B. On-Page SEO
> [Detailed checklist](02-on-page-seo.md)

- [ ] Unique title tag per page (< 60 characters, primary keyword near start)
- [ ] Unique meta description per page (< 160 characters, includes primary keyword)
- [ ] One H1 per page containing the primary keyword
- [ ] Logical heading hierarchy (H1 > H2 > H3, no skipping levels)
- [ ] Alt text on all images (descriptive, includes keyword where natural)
- [ ] Strategic internal linking connecting related content across domains
- [ ] Descriptive anchor text (not "click here" or "read more")
- [ ] Open Graph tags for social sharing (og:title, og:description, og:image)
- [ ] Twitter Card tags (twitter:card, twitter:title, twitter:description)
- [ ] Keyword optimization without stuffing
- [ ] Content above the fold is meaningful and relevant
- [ ] URLs are human-readable and keyword-inclusive

## C. Off-Page SEO
> [Detailed checklist](03-off-page-seo.md)

- [ ] Backlink profile audit (quality, diversity, toxic link identification)
- [ ] Consistent NAP (Name, Address, Phone) across all directories and profiles
- [ ] Social media profiles active and linked from all domains
- [ ] Brand mentions tracked across the web
- [ ] Cross-subdomain linking strategy implemented
- [ ] Industry directory listings (healthcare, media)
- [ ] Guest posting / PR / media appearance strategy

## D. Content Audit
> [Detailed checklist](04-content-audit.md)

- [ ] E-E-A-T signals present (Experience, Expertise, Authority, Trust)
- [ ] Author bios with credentials on all authored content
- [ ] Content freshness: publication and last-updated dates visible
- [ ] Comprehensive topic coverage on core subjects
- [ ] Source citations and external references included
- [ ] No thin content (< 300 words with no substance)
- [ ] No duplicate content across domains/pages
- [ ] Content matches user search intent for target keywords
- [ ] Healthcare-specific claims are sourced and verifiable

## E. AI/LLM Optimization (GEO)
> [Detailed checklist](05-ai-llm-optimization.md)

- [ ] robots.txt allows AI search crawlers (Claude-SearchBot, OAI-SearchBot, PerplexityBot)
- [ ] robots.txt allows AI real-time retrieval (ChatGPT-User, Claude-User)
- [ ] robots.txt allows AI training crawlers (ClaudeBot, GPTBot) for maximum visibility
- [ ] llms.txt file deployed at each domain root
- [ ] Schema.org JSON-LD on every page (Organization, Person, Article, FAQ, etc.)
- [ ] Critical content is server-side rendered (not hidden behind JavaScript)
- [ ] Content uses structured formatting (bullet points, numbered lists, clear headings)
- [ ] FAQ sections with actual question-and-answer format
- [ ] Summary/conclusion paragraphs present in long-form content
- [ ] Short paragraphs (2-3 sentences max) for AI extractability
- [ ] Citations to authoritative sources (CMS data, academic papers, federal registers)
- [ ] Factual, verifiable claims with supporting data and statistics
- [ ] Content answers common questions directly and concisely
